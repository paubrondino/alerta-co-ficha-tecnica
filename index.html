Ficha técnica

Alerta CO es un prototipo de monitoreo de monóxido de carbono. Utiliza un sensor MQ-7, una placa ESP32 y una conexión Wi-Fi para transmitir las lecturas a una plataforma web.

01. Sensor MQ-7

Detecta la presencia de monóxido de carbono en el ambiente. Sus lecturas son recibidas por la placa ESP32 para ser procesadas por el programa.

02. Placa ESP32

Es la unidad de procesamiento del dispositivo. Lee la señal del sensor, ejecuta la programación y permite la comunicación con la plataforma mediante Wi-Fi.

03. Pantalla OLED

Permite visualizar mensajes y estados del dispositivo directamente en el equipo.

04. Indicadores de alerta

El LED y el buzzer proporcionan señales visuales y sonoras cuando se cumplen las condiciones establecidas en el programa.

Componentes principales

MQ-7 Sensor utilizado para detectar monóxido de carbono.
ESP32 DevKit Procesamiento de lecturas y conexión Wi-Fi.
Pantalla OLED SSD1306 Visualización local de mensajes y estados.
LED y buzzer Indicadores visuales y sonoros del sistema.

¿Cómo funciona?

El sistema sigue una secuencia de lectura, procesamiento y transmisión de datos.

Sensor MQ-7 → ESP32 → Wi-Fi → Plataforma web

Conexiones del prototipo

  • Sensor MQ-7: entrada analógica GPIO 34.
  • Pantalla OLED: comunicación I²C por GPIO 21 y GPIO 22.
  • LED indicador: GPIO 18.
  • Buzzer: GPIO 19.
  • Comunicación con la plataforma: Wi-Fi.
Importante: Alerta CO es un prototipo educativo. Las lecturas del MQ-7 requieren calibración para estimar concentraciones en ppm. Este dispositivo no reemplaza detectores certificados ni sistemas profesionales de seguridad contra monóxido de carbono.
